# API Reference

Base URL (local dev): `http://localhost:8000`
Interactive docs (auto-generated by FastAPI): `http://localhost:8000/docs`

All responses are JSON. Timestamps are ISO 8601 UTC.

---

## GET /api/motor/status
Connection + system status summary.

**Response**
```json
{
  "motor_id": "MOTOR-001",
  "connection_status": "DEMO",
  "demo_mode": true,
  "last_updated": "2026-09-03T10:15:42.120Z",
  "system_status": "OK"
}
```
`connection_status` is one of `CONNECTED`, `DISCONNECTED`, `DEMO`.

---

## GET /api/sensors/latest
Latest reading per parameter, with status, trend, and 24h min/max.

**Response**
```json
{
  "motor_id": "MOTOR-001",
  "demo_mode": true,
  "parameters": [
    {
      "parameter": "temperature",
      "unit": "°C",
      "value": 45.2,
      "status": "NORMAL",
      "trend": "up",
      "min_value": 41.0,
      "max_value": 47.8,
      "last_updated": "2026-09-03T10:15:42.120Z",
      "connected": true
    }
  ]
}
```
If a sensor hasn't reported in the last 15 seconds, `connected` becomes `false` and `value` is `null` (never coerced to 0).

## GET /api/sensors/history?range=1h&parameter=temperature
`range`: one of `1m`, `5m`, `30m`, `1h`, `24h`.

Returns an array of raw rows:
```json
[
  {"id": 1042, "motor_id": "MOTOR-001", "timestamp": "...", "temperature": 45.2, "current": 2.8, "vibration": 1.4, "rpm": 1420, "source": "demo"}
]
```

## POST /api/sensors/data
Endpoint the microcontroller (or the demo generator) posts to.

If `DEVICE_API_KEY` is set in `.env`, requests must include header `X-Device-Api-Key`.

**Request**
```json
{
  "motor_id": "MOTOR-001",
  "temperature": 45.2,
  "current": 2.8,
  "vibration": 1.4,
  "rpm": 1420,
  "source": "real"
}
```
Posting with `"source": "real"` automatically stops the demo generator, so real hardware data always takes priority.

**Response** `201`
```json
{ "status": "ok", "id": 1043 }
```

## GET /api/health
Rule-based motor health score (see `services/health_service.py` for the exact formula).

```json
{
  "motor_id": "MOTOR-001",
  "health_score": 87.0,
  "status": "GOOD",
  "risk_level": "LOW",
  "recommended_action": "No action required - continue normal operation and routine monitoring.",
  "last_fault_detected": null,
  "last_fault_timestamp": null,
  "operating_hours": 0,
  "basis": "Rule-based score: 100 minus a penalty for each parameter currently in WARNING (-15) or CRITICAL (-35)..."
}
```

## POST /api/predict
Runs the ML fault-classification model, if one has been trained (see `ml/train_model.py`).

**Request**
```json
{ "temperature": 45.2, "current": 2.8, "vibration": 1.4, "rpm": 1420 }
```

**Response when no model is trained yet**
```json
{
  "model_available": false,
  "status": "MODEL_NOT_AVAILABLE",
  "failure_probability": null,
  "predicted_condition": null,
  "confidence": null,
  "remaining_useful_life_hours": null,
  "note": "No trained fault-classification model is available yet. ...",
  "prediction_timestamp": "2026-09-03T10:15:42.120Z"
}
```

**Response once a model exists**
```json
{
  "model_available": true,
  "status": "WARNING",
  "failure_probability": 0.18,
  "predicted_condition": "Normal",
  "confidence": 0.91,
  "remaining_useful_life_hours": null,
  "note": "Prediction from trained model (held-out test accuracy at training time: 0.94). RUL is not implemented...",
  "prediction_timestamp": "2026-09-03T10:15:42.120Z"
}
```
Remaining Useful Life stays `null` until a separate RUL regression model is built and wired in - it is never fabricated.

## GET / PUT /api/motor/details
Motor nameplate data (`motor_info` table). `PUT` overwrites the configurable fields.

## GET / POST /api/settings/demo-mode
```json
{ "enabled": true }
```
Toggling this on starts the demo generator; off stops it.

## WS /ws/live
WebSocket channel. On every new sensor row (real or demo), all connected clients receive:
```json
{
  "type": "sensor_update",
  "demo_mode": true,
  "motor_id": "MOTOR-001",
  "timestamp": "...",
  "data": { "temperature": 45.2, "current": 2.8, "vibration": 1.4, "rpm": 1420 },
  "health_score": 87.0,
  "health_status": "GOOD",
  "new_alerts": []
}
```
